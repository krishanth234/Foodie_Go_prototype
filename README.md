# 🍔 FoodieGo - Food Delivery App Prototype

A modern food delivery mobile application prototype designed in Figma, showcasing a complete user journey from onboarding to checkout.

## 📱 Prototype Overview

FoodieGo is a food delivery application prototype featuring:

* Onboarding Screen
* Home Screen
* Restaurant Details
* Food Details
* Cart & Checkout

## 🎨 Designed With

* Figma
* Interactive Prototyping
* Mobile UI/UX Design

## ⚠️ Important

For the best viewing experience:

1. Open the Figma Prototype link.
2. Click the **Display Settings** icon in the top-right corner.
3. Select **Fit width and height** under Scaling Options.

This ensures the prototype is displayed correctly across different screen sizes.

## 🚀 User Flow

### 01. Onboarding

* Welcome screen
* Get Started action

### 02. Home

* Browse food categories
* Search restaurants and dishes
* View popular restaurants

### 03. Restaurant Details

* Restaurant information
* Category tabs
* Food menu listing

### 04. Food Details

* Food description
* Ingredients
* Quantity selection
* Add to Cart

### 05. Cart & Checkout

* Order summary
* Delivery address
* Payment method
* Place Order
